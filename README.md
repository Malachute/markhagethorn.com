# Next.js static portfolio page

Homepage for markhagethorn.com. Uses [pnpm](https://pnpm.io) and Node 22 (Next 12 does not run on Node 25+).

To serve:
`pnpm dev`

To build:
`pnpm build`

Deploy: pushing to `main` builds and deploys to Firebase Hosting via GitHub Actions; pull requests get a preview channel.
